PiVo-ID 1.4M — Demo TTS Bahasa Indonesia

Fine-tune 1.4M parameter PiVo-1.4M untuk Bahasa Indonesia (16 kHz mono, ONNX 5,6 MB, suara Pi & Vo). Bagian v6 bilingual (Indonesia + Inggris) masih tersimpan; model sekarang fokus Indonesia saja karena Inggris menurun saat retrained. Unduh dari GitHub Release v1.1.0.

✍️ Coba langsung — generate di browser

Model jalan 100% di browser kamu via onnxruntime-web (4 file ONNX 5,6 MB di docs/models/, tanpa server, tanpa install). Ketik Bahasa Indonesia, pilih suara Pi (perempuan) / Vo (pria), klik Generate. Frontend = port JS dari src_id/frontend.py (token identik Python — teruji 10 kalimat paritas 100%).

python -I experiments/render_narration.py \
  --model pivo-id-v11 --lang id --voice-id 0 \
  --text "Selamat pagi, apa kabar?" --out coba.wav
